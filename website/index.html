Jury Evaluation Claims

The Four Non-Negotiable Invariants

These are product claims made to the iQOO hackathon jury. Breaking any one is worse than shipping less.

Constraint 01

Zero INTERNET Permission

The AndroidManifest declares only CAMERA and RECORD_AUDIO. It explicitly removes INTERNET and ACCESS_NETWORK_STATE using tools:node="remove" so no merged transitive library can inject network access.

<uses-permission android:name="android.permission.CAMERA" /> <uses-permission android:name="android.permission.RECORD_AUDIO" /> <!-- Stripped with tools:node="remove" --> <uses-permission android:name="android.permission.INTERNET" tools:node="remove" /> <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" tools:node="remove" />
Constraint 02

Pause Detector + Word List (No Video ML)

The step cutter is a pure silence run detector (≥1200ms) cross-referenced with a Hindi/Marathi linking-word vocabulary (phir, ab, uske baad). It contains zero video models and runs in milliseconds on a five-year-old budget phone.

// PURE KOTLIN. ZERO android.* IMPORTS. val isPause = silenceDurationMs >= policy.pauseMs val hasLinkWord = linkWordConfirmer.confirms(windowWords) if (isPause || hasLinkWord) { cutPoints.add(pauseMidpoint) }
Constraint 03

Mode Engine Contains Zero AI

Switching between EASY, HANDS, TALK, and TAP uses plain boolean logic over Schmitt triggers with a 400ms dwell latch. Decides in well under 10 milliseconds and guarantees zero UI flicker.

// Decides in <1ms. Every decision carries an on-screen reason string. when { inputs.easyMode -> ModeDecision(EASY, "EASY <- user setting") loud -> ModeDecision(HANDS, "HANDS <- room is loud ($db dBFS)") !held -> ModeDecision(TALK, "TALK <- phone is flat") else -> ModeDecision(TAP, "TAP <- held, quiet, close") }
Constraint 04

Warnings Advise, They Never Block

There is no disabled button in the entire app. Anything the phone cannot honestly measure (gloves, driving, user age, or task correctness) is left as a transparent setting, never an AI guess.

// No guess on whether work is "correct". // Scene check yields honest dHash score; user always retains full override. val sceneDiff = SceneHash.hammingDistance(liveHash, stepPhotoHash) if (sceneDiff > policy.sceneAdviseThreshold) { adviseWarning("Bench scene differs — hold steady or proceed") }
